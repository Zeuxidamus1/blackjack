# Blackjack

A standalone, play-money, six-deck blackjack table. Open `index.html` in a modern browser or serve via GitHub Pages.

Features: cryptographically shuffled 312-card shoe, 75% penetration, S17, 3:2 blackjack, doubles with face-up / face-down selection, splits, insurance, custom even-money dealer-bust side bet and 8:1 TriLux three-card poker side bet. Default buy-in $500. Side bets $10–$500.

Note: this is a first playable implementation and not a regulated casino engine. Payouts and statistics need independent QA before production use. No real money, payments, or wagering integration.
